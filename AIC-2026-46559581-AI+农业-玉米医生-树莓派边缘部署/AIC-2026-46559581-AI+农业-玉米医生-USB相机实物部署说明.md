# AIC-2026-46559581 AI+农业 玉米医生 — USB 相机实物搭建与部署说明

> 对应代码包：`corn_ws/src/corn_doctor_ros2`（`camera_node.py` / `detector_node.py` / `launch/corn_doctor.launch.py`）
> 定位：手持式"玉米医生"实物机 —— USB 相机取景 → 树莓派边缘推理 → 语音/屏幕播报病害结论。
> 配套定位方案（三维坐标输出）见《RealSense三维定位方案》。

## 1. 硬件清单（BOM）

| 部件 | 规格 | 备注 |
|---|---|---|
| 树莓派 | 4B/5，≥4 GB | 系统镜像：Ubuntu Server 22.04 + ROS 2 Humble（或 Raspberry Pi OS + 预编译 ros2） |
| USB 相机 | 任意 UVC 免驱相机（罗技 C270/C920、淘宝 30 元免驱模块均可） | 640×480 自动曝光即可，模型输入只有 224×224，无需高分辨率 |
| TF 卡 | ≥32 GB A1 级 | |
| 电源 | 树莓派官方 5V/3A+ | 相机走 USB 供电，无需额外供电 |
| 可选 | 小屏幕 / USB 声音模块 / 云台支架 | 展示用：屏幕显示结论，或串口接语音播报板朗读"检测到普通锈病" |
| 结构 | 相机支架/手持外壳 | 相机镜头距叶片 15–40 cm 取景 |

## 2. 接线与装配

1. TF 卡烧录系统，树莓派上电开机，配置 Wi-Fi/SSH；
2. USB 相机插任意 USB 口（建议直插主板口，不经 HUB）；
3. `ls /dev/video*` 确认设备出现（UVC 相机即插即用，无需驱动）；
4. 可选串口外设（语音板/单片机）接 USB 转 TTL（`/dev/ttyUSB0`）。

## 3. 软件部署（硬件到手后照做即可）

```bash
# 1) ROS 2 Humble 安装后，装 Python 依赖
pip3 install onnxruntime opencv-python-headless numpy

# 2) 编译工作空间
cd ~/corn_ws
colcon build --symlink-install
source install/setup.bash

# 3) 摄像头权限（首次）
sudo usermod -aG video $USER && 重新登录

# 4) 一键启动（相机采集 + 病害识别）
ros2 launch corn_doctor_ros2 corn_doctor.launch.py
# 换相机编号/识别间隔:
# ros2 launch corn_doctor_ros2 corn_doctor.launch.py camera_index:=1 infer_interval:=3.0
```

启动后对准玉米叶片，终端每 2 秒输出一次结论，同时发布到话题：

```
结论: 生病 | 普通锈病 置信度=0.97 | 推理 210 ms
```

## 4. 话题与集成接口

| 话题 | 类型 | 内容 |
|---|---|---|
| `/image_raw` | sensor_msgs/Image | 相机图像（bgr8 640×480，默认 5 Hz） |
| `/corn_doctor/result` | std_msgs/String | 结论 JSON，示例： |

```json
{"verdict": "生病", "class": "Common_Rust", "class_cn": "普通锈病",
 "confidence": 0.97, "infer_ms": 210.5, "stamp": "2026-10-19 20:30:01"}
```

任何展示端（小屏幕 Flask 页、语音播报节点、LED 灯板）只需订阅 `/corn_doctor/result` 解析 JSON 即可，与识别逻辑解耦。

## 5. 内置防误判机制（detector_node 已实现）

1. **光照预检**：画面平均亮度低于 `dark_mean=45` 判定"光照不足，请对准玉米叶片"，不进模型；
2. **叶片预检**：HSV 绿色像素占比低于 `leaf_min_ratio=2%` 判定画面无叶片，防把墙/手判成病叶；
3. **置信度门槛**：最高概率低于 `min_conf=0.6` 时报"不确定"，不做结论；
4. **结论变化才打印**，防刷屏。

## 6. 实物演示流程建议（答辩/视频）

1. 上电启动 → 屏幕显示"玉米医生就绪"；
2. 对准健康叶片 → 播报"健康"；
3. 对准锈病叶 → 播报"检测到普通锈病，置信度 97%"；
4. 换叶斑病/灰斑病叶 → 依次演示三类病害；
5. （加分项）接 RealSense 走 corn_detect 包，演示三维坐标引导云台指向病叶。

## 7. 常见问题排查

| 现象 | 排查 |
|---|---|
| `无法打开摄像头 0` | `ls /dev/video*` 无设备 → 换 USB 口/线；有多个设备号时 `camera_index:=1` 试 |
| 画面卡顿、推理 >1 s | 树莓派降频/散热不足 → 加散热壳；`infer_interval:=3.0` 降低频率 |
| 一直提示"光照不足" | 田间强逆光或夜晚 → 补光；或调低 `dark_mean` 参数 |
| 一直提示"未检测到叶片" | 叶片非典型绿色/枯黄 → 适当调低 `leaf_min_ratio`（如 0.01） |
| 结论明显不准 | 确认镜头距叶片 15–40 cm、叶片占画面主体；模型文件为 `models/corn_doctor.onnx` |
